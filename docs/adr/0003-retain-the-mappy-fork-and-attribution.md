# 0003: Retain the Mappy fork and attribution

Gratis began as a copy of harbingerftw/Mappy 3.2.0.0, with MidoriKami's Mappy and bundled KamiLib code providing the map window, marker handling and plugin foundation. Continue that fork under AGPL-3.0, retaining original attribution and licence notices rather than treating it as an independent rewrite. This preserves the inherited working code while carrying its provenance and licensing constraints; alternate licensing would require a separate provenance and rewrite plan.
